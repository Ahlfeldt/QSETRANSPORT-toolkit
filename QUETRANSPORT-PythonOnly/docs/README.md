# Documentation guide

QUETRANSPORT-PythonOnly is documented as a complete standalone toolkit. No
files from the mixed Python–MATLAB version are required.

## Start here

- [Root README](../README.md): overview, installation and quick start.
- [User guide](../USER_GUIDE.md): practical instructions for a new application.
- [Python-only codebook](QUETRANSPORT_PYTHON_CODEBOOK.md): model, inputs,
  scenarios, outputs and interpretation.

## Technical references

- [Data contract](DATA_CONTRACT.md): schemas, identifiers, interpolation and validation.
- [Workflow](WORKFLOW.md): GRID, TTMATRIX, Python inversion, simulation and reporting.
- [Model architecture](MODEL_ARCHITECTURE.md): modules, closures and numerical conventions.

The documents describe the implemented Python-only interface. Generated data
and outputs should be interpreted together with the resolved runtime
configuration saved by each run.
